# windows-bootstrap

Reproducible Windows machine setup for an annual clean reinstall.
Three layers, all in this Git repo so the whole thing is infra-as-code:

- **Apps** — winget (GUI apps + dev tools)
- **Config** — [chezmoi dotfiles](https://github.com/julianbrennum/chezmoi) (SSH config, Windows Terminal)
- **Secrets** — Keeper (never committed); chezmoi pulls them at apply time

---

## The yearly ritual

### Before you wipe (on the OLD install)

```powershell
# Refresh every manifest from the machine's current state, then commit.
pwsh -ExecutionPolicy Bypass -File .\export\export-current.ps1
```

### After reinstall (on the FRESH install)

Run these in the built-in **Windows PowerShell 5** (no installs yet — winget is pre-installed on Win 11):

```powershell
# 1. Get Git and PowerShell 7
winget install --id Git.Git --exact --accept-package-agreements --accept-source-agreements
winget install --id Microsoft.PowerShell --exact --accept-package-agreements --accept-source-agreements
```

Close and reopen the terminal so `git` is in PATH, then:

```powershell
# 2. Clone this repo
git clone https://github.com/julianbrennum/windows-bootstrap.git
cd windows-bootstrap

# 3. Run bootstrap (elevated — right-click → Run as administrator)
pwsh -ExecutionPolicy Bypass -File .\bootstrap.ps1
```

`bootstrap.ps1` installs all apps, then calls `restore-dotfiles.ps1` which installs chezmoi and applies your dotfiles automatically — no manual chezmoi step needed.

`bootstrap.ps1` is idempotent: re-running it reconciles to the manifests,
so it's also a fine "drift repair" tool mid-year.

### Curating the app list

Edit `packages/winget.dsc.yaml` to add or remove apps before running bootstrap —
that file is what gets installed. `winget-packages.json` is just a raw snapshot
for reference and is not used during install.

## App manifests

Everything goes through winget. There is one manifest per machine:

| File | Machine |
|---|---|
| `packages/winget-desktop.dsc.yaml` | `8K-WORKSTATION` |
| `packages/winget-laptop.dsc.yaml` | *(set hostname in bootstrap.ps1)* |

`bootstrap.ps1` auto-selects the right file based on `$env:COMPUTERNAME`.
To add your laptop's hostname, edit the `$hostManifests` table near the top of `bootstrap.ps1`.

`winget-packages.json` is a raw snapshot regenerated by the export script —
useful for auditing but not used during bootstrap.

## Secrets & SSH

Nothing secret lives in this repo.

**Fleet SSH → NetBird SSH** (identity-based). EW servers are reached over
the NetBird mesh using OIDC via Zitadel — no stored keys. After a reinstall:
install NetBird, run `netbird up`, and `ssh user@<peer>` works. See
[NETBIRD-SSH.md](NETBIRD-SSH.md) for full setup.

**Break-glass → one key in Keeper.** One emergency SSH keypair + Hetzner
console credentials live in Keeper so a NetBird/Zitadel outage can't lock
you out. Emergency use only.

**Everything else → Keeper.** API tokens (Cloudflare, Komodo…), passwords,
Git signing keys, SSH to non-mesh hosts. chezmoi pulls them at apply time:

```
$env:CF_API_TOKEN = "{{ keeper "RECORD_UID" "password" }}"
```
